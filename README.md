找回密码的链接被人转发到群里后，第二天有人用它把账号密码改掉了：其一，令牌用递增序号生成，可枚举；其二，令牌明文入库，泄露即用；其三，过期时间按小时写死，忽略配置；其四，查找不校验绑定用户，拿别人令牌也能改密码；其五，消费不是原子操作，并发两次都能成功；其六，撤销只删当前一条，其余令牌仍可用；其七，限流只按令牌计数，枚举不同令牌不受限；其八，配置校验不检查有效期上限；其九，批量处理复用存储游标，后一个请求命中前一个的令牌；其十，失败响应区分用户存在与否，可用于账号枚举。engine/reset/token.py 是核心，tests/reset/test_token.py 15个红。要修的是：按上面的顺序把 10 个缺陷逐个修掉。

运行方式
========

在仓库根目录执行 pytest tests -q，预期恰好 15 failed，且没有 error。
